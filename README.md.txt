
# Password Strength Checker

A simple cybersecurity project developed in C++ to evaluate password strength based on common password composition rules.

## Features
- Checks minimum password length
- Detects lowercase letters
- Detects uppercase letters
- Detects numeric digits
- Detects special characters
- Classifies passwords as Very Weak, Weak, Medium, Strong, or Very Strong

## Technologies Used
- C++
- Standard C++ Library

## How to Run

1. Install a C++ compiler such as GCC.
2. Clone or download this repository.
3. Open a terminal in the project directory.
4. Compile the program:

   `g++ password_checker.cpp -o password_checker`

5. Run the executable:

   `./password_checker`

   On Windows, run `.\password_checker.exe`.

## Learning Outcomes
- Practiced C++ functions and loops
- Used string handling and character classification
- Explored basic password security principles

## Disclaimer
This is an educational password-strength estimation tool. It does not measure actual password entropy or guarantee password security.
